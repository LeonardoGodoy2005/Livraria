# 📚 Sistema de Biblioteca

Projeto desenvolvido em **Java** para gerenciar livros, autores e empréstimos por meio de um sistema de console.

### Funcionalidades
- Cadastro de livros e autores
- Listagem e busca de livros
- Empréstimos e devoluções
- Histórico de empréstimos
- Salvamento de dados em arquivo

### Tecnologias
- Java
- Programação Orientada a Objetos (POO)
- Collections (`ArrayList`)
- Serialização de objetos

### Como executar

```bash
javac *.java
java Main
```
